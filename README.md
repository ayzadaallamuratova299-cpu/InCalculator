# InCalculator

An aesthetic and simple calculator web app with PWA support.

## Features

- ✨ Beautiful gradient UI with purple theme
- 📱 Fully responsive design
- ⌨️ Keyboard support (Enter, Backspace, Escape, %)
- 🔢 Basic arithmetic operations (+, −, ×, ÷)
- % Percentage calculations
- 🚀 Progressive Web App (PWA) - installable
- ⚡ Fast and lightweight

## How to Use

1. Open `index.html` in a web browser
2. Click buttons or use your keyboard to perform calculations
3. Install as a PWA by clicking "Install" in your browser

## Keyboard Shortcuts

- `0-9` - Enter numbers
- `+`, `-`, `*`, `/` - Operations
- `Enter` or `=` - Calculate
- `Backspace` - Delete last character
- `Escape` - Clear all
- `%` - Percentage

## Installation

Clone the repository and open `index.html` in your browser, or deploy to any web server.

```bash
git clone https://github.com/ayzadaallamuratova299-cpu/InCalculator.git
```

Then open `index.html` in your preferred browser.
